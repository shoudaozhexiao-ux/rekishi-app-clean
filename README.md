# 六十年の連環：歴史の比較と今年の予想

APIキーや有料AIサービスを使用せず、公開歴史資料とローカルの分類ルールで動くStreamlitアプリです。

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

Secretsの設定は不要です。OpenAIへの接続・課金処理はありません。

## 過去と60年後の比較

- ブラウザの端末時刻から今年を取得し、開いたままの年越しにも対応します。
- 今年の80年前〜61年前の20年から比較年を選び、日本・世界を切り替えられます。
- 選択年と、正確に60年後の出来事をWikipediaから取得します。
- 2026年なら1946〜1965年を選び、それぞれ2006〜2025年と比較します。
- 11テーマの分類語を使い、共通するテーマがある出来事を対応候補として最大10組表示します。
- 同じ語が多い組を優先し、出来事の使い回しを避けます。共通テーマがなければ無理に結びません。
- テーマの類似を見つける仕組みで、因果関係や60年周期の証明ではありません。

## 今年の予想

- 比較年の選択とは独立して、今年の正確に60年前の資料を取得します。
- 日本はWikipedia「年の日本」、世界は「年」の記事を参照します。世界記事には日本の出来事も含まれる場合があります。
- 2026年なら「1966年の日本」と「1966年」が根拠です。
- 各資料を外交・政治、科学・技術、経済・産業など11テーマに分類し、件数の多いテーマから最大3件ずつ予想します。
- 予想文はテーマ別の定型文です。根拠となった出来事と理由も表示します。AI生成ではありません。
- 歴史の類似から考える仮説であり、災害の日時や発生などを断定するものではありません。

## データ更新と出典

表示、年・地域の変更、再取得ボタンの操作のたびに、必要な資料の最新版を取得します。
各資料の「出来事」節から最大36件を年間に分散して抜粋し、比較と予想はこの範囲で処理します。
出典の版へのリンクと取得時刻を表示します。資料はWikipedia由来の抜粋で、CC BY-SAに従います。
取得できない資料は該当欄にエラーを表示し、史実を作って補いません。他の取得できた欄は使用できます。
ニュース欄は独立した表示で、予想の根拠には使用しません。

```bash
python -m unittest discover -s tests -v
```
