=== ござい歴史アプリ ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

== 機能 ==
[gozai_history_app] を記事のショートコードブロックへ置くと、歴史の60年差比較、今年の予想、ニュース検索を表示します。
StreamlitやAI APIキーは不要です。既存のStreamlit版の分類語・比較順位・予想定型文を移植しています。
外部の文字列は画面へHTMLとして挿入せず、文字列として表示します。JavaScript/CSSは別ファイルで読み込むため、記事本文の文字変換の影響を受けません。

== 導入 ==
1. WordPressの「プラグイン」→「新規プラグインを追加」→「プラグインのアップロード」でZIPを選びます。
2. 「今すぐインストール」のあと「プラグインを有効化」を押します。
3. 最初はテスト用の下書きに [gozai_history_app] を置き、プレビューで確認してください。
4. 日本／世界の切り替え、比較年の変更、今年の予想と出典、ニュース検索を確認します。
5. 確認後に既存記事のStreamlit埋め込みを置き換えます。記事公開は手動です。
無効化すれば機能は停止します。既存Streamlit版はそのまま残せます。

== 必要なサーバー環境 ==
PHP DOM拡張、SimpleXML拡張、HTTPSでの外部通信が必要です。
取得先は ja.wikipedia.org と news.google.com に固定し、リダイレクトは追跡しません。
WordPress REST APIの /gozai-history/v1/history と /gozai-history/v1/news は公開の読み取り専用です。
年は1800年からサーバーの現在年、地域はjapan/world、検索語は1〜80文字に制限します。

== データ取得と保存 ==
歴史資料は最大1時間、ニュースは最大15分キャッシュします。
上流が利用できない場合は24時間以内に取得した保存済みデータを、その旨と取得時刻を表示して使用します。
失敗は1分間キャッシュし、同じ資料を同時取得する処理と、全体で毎分60回を超える上流取得を抑制します。
匿名閲覧者の識別子は独自には記録しません。ニュース検索語に個人情報を入力しないでください。
履歴の出典はWikipediaの対象記事と版へのリンクです。「出来事」節から最大36件を年間に分散して抜粋します。
Wikipedia由来の抜粋はCC BY-SAです。予想はテーマ別ルールによる仮説で、史実の因果関係や周期性を証明しません。
